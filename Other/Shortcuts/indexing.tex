\section{\textbf{Module Codes}}
Each module code will consist of three digits. The first digit refers to the year the module is being taken, 
the second refers to what semester it is taken (0 for a yearlong module), the final digit then refers to 
the module itself (See Section 4 for full list of module codes).
\begin{itemize}
    \item 101 $\longrightarrow$ Linear Algebra
    \item 102 $\longrightarrow$ Mechanics
    \item 111 $\longrightarrow$ Single Variable Calculus
    \item 112 $\longrightarrow$ Introduction to Programming
    \item 113 $\longrightarrow$ Introduction to Probability
\end{itemize}
\vspace{2.5mm}
\section{\textbf{Subfolder Codes}}
Each module's folder is split up in to three subfolders each with their own code. 
\begin{itemize}
    \item 01 $\longrightarrow$ Class Notes
    \item 02 $\longrightarrow$ Problem Sets
    \item 03 $\longrightarrow$ Other
    \item 04 $\longrightarrow$ Questions
\end{itemize}
\vspace{2.5mm}
\section{\textbf{File Codes}}
Each file is named first off the date (year excluded), which is followed by two digits which seperate files 
created on the same day.
\begin{itemize}
    \item \textbf{Example} $\longrightarrow$ 1509-01 is the first file created on the 15th of September
\end{itemize}
